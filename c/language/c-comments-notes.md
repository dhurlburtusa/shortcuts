# C - Comments Notes

Two styles:

- Single-line
- Multi-line

**Single-Line Comments**

```c
// This is a comment.
printf("C is awesome!"); // Can be after code.
// printf("..."); // Can be used to comment out code.
```

Note: Added in C99 (1999).

**Multi-Line Comments**

```c
/*
This is a multi-line comment. It tends to be used for longer comments.
